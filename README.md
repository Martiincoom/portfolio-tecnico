# Portfolio Técnico

<text color="secondary">Sistemas Microinformáticos y Redes (SMR)</text>

## Bienvenido a mi portfolio

Este portfolio reúne la documentación técnica, actividades y prácticas realizadas durante mi formación en Sistemas Microinformáticos y Redes.

## Sobre el proyecto

El objetivo de este proyecto es organizar los conocimientos adquiridos a lo largo del curso mediante documentación estructurada, utilizando Markdown y Docsify.

## Contenidos

- **UT1 - Hardware y redes:** documentación pendiente de desarrollo.
- **UT7 - Aplicaciones Informáticas:** licencias de software y herramientas de documentación.

## Tecnologías utilizadas

| Herramienta | Uso |
|---|---|
| Visual Studio Code | Edición de archivos |
| Markdown | Redacción de documentación |
| Docsify | Visualización de la documentación |
| HTML | Configuración del proyecto |
| Git y GitHub | Control de versiones |
