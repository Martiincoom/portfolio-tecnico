# 7.1 Clasificación y licencias de software

## 1. Clasificación del software

El software se puede clasificar según su finalidad en tres tipos:

- **Software de sistema:** gestiona el hardware del ordenador. Ejemplo: Windows y Linux.
- **Software de programación:** permite crear programas. Ejemplo: Visual Studio Code y Python.
- **Software de aplicación:** permite realizar tareas concretas. Ejemplo: Word, Excel y Google Chrome.

## 2. Licencias de software

Una licencia es un contrato que establece las condiciones de uso de un programa.

| Tipo de licencia | Características | Ejemplo |
|---|---|---|
| Propietaria | Código cerrado y uso limitado | Windows |
| Freeware | Gratuito, pero no necesariamente libre | Google Chrome |
| Shareware | Versión de prueba limitada | WinRAR |
| GPL | Permite modificar y distribuir | Linux |
| MIT | Permite reutilizar y modificar el código | Node.js |

## 3. Software libre

El software libre permite al usuario:

1. Utilizar el programa para cualquier propósito.
2. Estudiar y modificar su código.
3. Distribuir copias.
4. Mejorar el programa y compartir las mejoras.

> [!IMPORTANT]
> Software libre no significa necesariamente gratuito. Se refiere a las libertades que tiene el usuario, no a su precio.

## 4. Comprobación de licencias

En Windows podemos consultar información de un programa utilizando PowerShell:

```powershell
winget show VideoLAN.VLC
```

Este comando muestra información sobre VLC, incluyendo datos de su paquete.

## 5. Conclusión

Es importante conocer las licencias de software antes de instalar, utilizar o distribuir un programa para respetar los derechos de sus autores.
